Safari Technology Preview Release 246 is now available for download for macOS Golden Gate and macOS Tahoe. The release documents 313,555 WebKit changes across Accessibility, CSS, Canvas, Editing, Forms, HTML, Images, JavaScript, Media, Networking, Rendering, SVG, Scrolling, Storage, Web API, Web Extensions, Web Inspector, WebGPU, and WebRTC, including support for light-dark() with image values, the font-variant-emoji property, word-break: auto-phrase, and color-mix() enhancements.
